# Classes and Objects Revision — Week 6, Category C

Java solutions for all five problems in `Classes and Objects Revision_Week6_Category_C_Assignment.pdf`.

1. **Library Inventory Management** — constructor, instance method, array of objects.
2. **Payroll Salary Management** — private fields, validation, bonus crediting, tax deduction, read-only net salary.
3. **Employee Profile Creation** — overloaded constructors and `this(...)` constructor chaining.
4. **Exam Hall Ticket Reference Management** — reference aliasing and `==` identity comparison.
5. **Employee and Company Information Management** — shared static fields, static counter, class-level method.

## Compile and run
Use Java 8 or later. From `src`, compile and run one file at a time, e.g.:

```bash
javac Problem1LibraryInventoryManagement.java
java Problem1LibraryInventoryManagement
```

Each file has its own public top-level class and `main` method.
